# v0.5.0 — Kit-specific bard spell progression

Bards can now use different native spell-slot tables by kit, through EEex.

- **420: shared progression provider.** Adds the engine hook and registration API.
  Installing the provider alone leaves class defaults unchanged.
- **421: base Bard policy.** Bard and Jester use the Icewind Dale curve through
  seventh-level spells; Blade and Skald use the original BG curve through sixth.
- **Bardic Wonders integration:** use
  [Bardic Wonders Chriz Balance Patch v2.9c-balance.6](https://github.com/Chrizhermann/Bardic-Wonders-Chriz-Balance-Patch/releases/tag/v2.9c-balance.6)
  component **3010**. Dancer uses the original curve through sixth; Kapellmeister
  and optional Darkbloom reach eighth; other supported bard kits reach seventh.
  Existing bonus slots, slot penalties, caster levels and innate/HLA access remain.

Install after the desired kits and description-changing tweaks: **420 → 421 → 3010**.
Standalone users may choose **420 → 3010** without changing the base Bard policy.
Descriptions reflect the selected progression. SCS, SR, CDTweaks and the collection
are not prerequisites. The provider leaves CDTweaks' shared table intact and selects
private tables for registered kits; unregistered kits retain native progression.
Darkbloom's existing SR spell-import issue is separate from this feature.

Requires Windows BG2EE/EET or IWDEE with compatible EEex. The installer checks the
required EEex capabilities and one compatible native instruction sequence rather
than enforcing an exact version or file address. The relevant layout was inspected
in BG2EE and IWDEE 2.7.3; EEex 1.2 and 1.3 supply the required APIs.

The user reported a successful BG2EE/EET in-game check. Focused LuaJIT and disposable
WeiDU checks cover tables, hook preparation, IWDEE installation, optional Darkbloom
and standalone dependencies. **IWDEE in-game verification remains pending.**
Normal level-up applies the new slot capacities; this release does not automatically
migrate saved spellbooks on load or change spell knowledge.

All v0.4.0 components remain included with their existing acceptance status.
The Windows ZIP includes the setup executable, mod files, installer, documentation
and licenses. No game executable or captured game binaries are included.
