# v0.8.11 — Every component writes its result, whatever the game files hold

BG Rebalance now writes the result each component defines instead of treating the old game data
as a compatibility test. A player edit or another mod's version of the same spell, item, kit,
creature or table no longer stops the install, produces an old-data warning or skips a component.

- **The Tempus bundle writes its complete result.** Weapon training, Holy Power, Chaos Tides,
  Divination Toll, specialization APR and their descriptions no longer depend on the previous
  layout of the kit's resources.
- **Spell Revisions, SCS and cross-cutting work now do the same.** This covers the anti-magic,
  Hardiness and Bracers changes; SCS spell and readiness adjustments; Emotion, Hope and combat
  clouds; and the shared setup they use.
- **The remaining balance work is equally direct.** Flail of the Ages, weapon access, bard
  progression, dragon changes, EET elemental arrows and potion changes write their selected
  results regardless of edited or extra old data.

Real requirements remain. The balance components target BG2:EE/EET (the bard provider and its
default progression also support IWD:EE); EEex is still required where a runtime component uses
it, and a subcomponent or kit still needs the base component or supplied content it builds on.
The release preserves mechanics a component deliberately does not own, keeps independent bard
registrations, and still prevents duplicate full and standalone installs.

Automated checks: the full offline suite passes, 957 tests with 26 skipped. It exercises decided
output from changed values and text, missing and extra effects, base-game and modded input, and
repeat application.

Also fixed: the bard progression tables (420) are copied by their exact file names, so WeiDU on a
case-sensitive file system finds them. Windows was not affected.

Lab: the lead installed all **466 of 466** components of a full Chriz Easy BG Recommended
BG2:EE 2.7.3.0 + EET installation using commit 7936bd8, the same component code as this release.
There were no errors and no new BG Rebalance warnings. A start test loaded a save and found the
kit-list, bard-progression, Time Stop 360 and physical-resistance 310 runtimes.

Not tested: playing the changed content, or installation over other mods' edited versions beyond
the synthetic fixtures. The lab start test is not gameplay acceptance.
