# v0.7.0 — Flail of the Ages

The Flail's Slow is powerful, but enemies now get a saving throw. Its +5 upgrade
also stops blocking your Haste.

- **New component 302:** Slow allows a save vs. breath at **-2 for +3**, **-4 for
  either +4 version**, and **-6 for +5**. Its trigger chance, duration and weapon
  damage are unchanged. Spell Revisions' associated Haste removal shares the save.
- **+5 Free Action keeps its useful protections** and permits Haste and Improved
  Haste. Other Free Action spells and items are not changed.
- Item descriptions reflect these rules without overwriting shared game text.

Requires BG2:EE/EET; EEex is not required. Install after Spell Revisions, SCS and
other changes to these items or their descriptions. The English base-game items
and CEBG's English EET/SR/SCS/Artisan/UB variants have automated coverage. Unknown
item structures or text stop safely rather than receiving a speculative patch.

Thirteen focused real-WeiDU tests pass, covering SR/non-SR, both effect layouts,
preservation, repeated application, exact uninstall and existing TLK strings.
Full current CEBG descriptions also passed an isolated check. In-game acceptance
is still pending and will use the next combined CEBG test install. This release
does not edit saves or provide an existing-game hotpatch.

All previous components remain available with unchanged behavior. The Windows ZIP
includes the mod, setup executable, documentation and licenses. Captured game
resources used in local tests are not included.
