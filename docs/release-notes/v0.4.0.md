# v0.4.0 — Optional Apex Dragons

Two new independent options, preserving all v0.3.2 fixes:

- **110: lethal dragon claws and bites.** Requires SCS Smarter Dragons and EEex.
  **A failed save can cause permanent death: a chunked companion cannot be raised
  or resurrected normally.** Firkraag: 15% chance / death save -4. Nizidramanii'yt
  and Saladrex: 10% / -2. Thaxll'ssillyia and the Watcher's Keep guardian: 5% / -2.
  Activates on SCS Dragon Hardcore/Insane (game Hard/Insane when using its slider).
  The physical rider bypasses Death Ward, death immunity, Stoneskin and physical
  resistance. Weapon immunity can prevent a qualifying hit; plot minimum HP and
  native gore/anti-chunking settings remain respected.
- **111: less frequent wing buffet.** The same five encounters use an 18-second
  cooldown instead of 6 seconds. Works at all their existing difficulty settings;
  does not require EEex or component 110.

No new HP, aura, escort or spell changes; no Adalon or ToB expansion. Other users
of shared scripts keep their existing behaviour. Install after SCS 6540. The two
options work independently; normal menu order is 110 then 111.

The existing implementation was checked with isolated WeiDU installation/rollback,
script and resource tests plus a Lua simulator. **Native combat and existing-save
acceptance are pending** for the combined CEBG candidate. This release is not an
automatic hotpatch and does not migrate saved creatures or active effects.

The Windows ZIP includes the setup EXE, source TP2, mod folder, README, changelog,
these notes and licenses. It does not include game files or test captures.
