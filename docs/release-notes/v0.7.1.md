# v0.7.1 — Apex Dragons installation fix

Apex Dragons could refuse to install on a valid SCS setup. SCS uses two ways of
storing its difficulty settings, and our component only supported one of them.
It now supports both.

The dragon abilities, chances and difficulty thresholds have not changed. Other
SCS combat behaviour is preserved. Wing Buffet and the other components are unchanged.

Automated checks cover both difficulty systems, repeated application, unrelated
script preservation and exact uninstall. The actual dragon resources from the
failed CEBG installation also passed through the public installer in a disposable
test game. These checks do not claim a new in-game combat playtest.

An already-stopped CEBG installation still needs a checked recovery; simply
downloading this archive does not change its recorded state. No saves are patched.
