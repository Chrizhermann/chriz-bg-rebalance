# v0.6.0 — Emotion, Courage / Emotion, Hope exclusivity

Emotion, Courage and Emotion, Hope no longer stack on the same creature.

- **301: mutually exclusive beneficial Emotions.** Casting either spell removes the
  other from each affected creature, so the last one applied wins. Recasting the same
  spell refreshes it instead of stacking. The component also fixes the installed Courage
  defect that let Courage stack with itself.
- **Courage:** +1 THAC0, +3 damage and +5 Hit Points for 300 seconds; ends fear and
  morale failure, including Emotion, Fear, Horror and Innate Horror.
- **Hope:** +2 morale, +2 THAC0, +2 damage and +2 to all saving throws for 300 seconds;
  ends Emotion, Hopelessness and Symbol, Hopelessness.
- **Hostile counterparts:** Fear removes Courage and Symbol, Hopelessness removes Hope
  in the same save/magic-resistance domain as their hostile effects. Emotion,
  Hopelessness keeps its unconditional Hope removal.

When IWDification or SCS already supplies the spells, 301 rebuilds them in place and
keeps their spell slots, icons, animation, scroll placement and SCS AI markers. Without
either, it adds both spells with the original Icewind Dale: Enhanced Edition icons and
animation, a character-sheet status entry, and learn-scrolls stocked wherever Enchanted
Weapon and Emotion, Hopelessness scrolls are sold.

Install **after** IWDification, SCS, Spell Revisions and other spell, scroll or store
overhauls. 301 deliberately overwrites the effective Courage/Hope mechanics and English
descriptions, and a spell mod installed later can overwrite it again. It makes no area,
creature, spellbook or save edits; a store already cached in a save may not show new
scrolls. Requires BG2EE/EET.

369 automated tests pass (26 dragon tests need locally captured SCS resources and skip on
a fresh clone). A disposable standalone install confirmed real spell delivery, the stat
changes and Hope/Courage replacement. The standalone status-list retest and a live check
on IWDification-supplied spells are not separately recorded; the author approved this
release based on earlier in-game testing; any issue will be fixed in a follow-up release.

All v0.5.0 components are unchanged. The Windows ZIP includes the setup executable, mod
files, installer, documentation and licenses, plus thirteen original IWDEE presentation
assets used only by the standalone path (provenance in
`chriz-bg-rebalance/resources/emotion_iwdee/README.md`). No IWDification or SCS binary is
included.
